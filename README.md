# Railway Block Planner

AI-powered automatic block planning system for Indian Railways — coordinates
maintenance scheduling across Engineering, Signal & Telecom, and Traction
Distribution departments.

## Structure
- Backend/ — FastAPI + SQLite backend with prioritization/scheduling engine
- Frontend/ — Dashboard, schedule view, and request intake UI

## Run

Backend:
cd Backend
source venv/bin/activate
python main.py

Frontend:
Open Frontend/index.html in a browser (or serve via a local static server).
